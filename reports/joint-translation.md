# Box 腕物联合平移：独立评价

加入粗接触后，物体及手物相对动作更接近真值，手腕误差和手部留出像素运动误差增加。这个结果支持粗接触的几何收益；采用标准中的手部动作与图像保真仍需要改善。

本轮是既有开发 box 的单初始化、固定旋转、仅平移消融。起点为 C 物体＋Raw 手，J0 进行双方图像与碰撞优化，JH 额外加入 HACO 粗接触。GT 仅在终态评分读取，三组沿用 Raw 首帧固定 canonical offset、原始未滤 GT 和相同观测集合。
